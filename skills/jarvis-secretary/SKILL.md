# 자비스 한국어 비서 세팅

디플래너가 만든 스킬입니다(문의 dplanner@outlook.kr). 자비스 원본은 https://github.com/adewaskar/jarvis (MIT 라이선스, 커밋 9ae5ec8 기준)입니다.

이 스킬을 받은 클로드 코드는 아래 단계를 순서대로 끝까지 진행합니다.

- 명령은 클로드 코드가 직접 실행합니다. 사용자에게 명령을 복사해 실행해 달라고 하지 않습니다.
- 사람만 할 수 있는 일(로그인, 권한 허용 버튼, 마이크 허용)은 그 화면을 열거나 주소를 알려 주고, 무엇을 누르면 되는지 한 줄로 말한 뒤 기다립니다.
- 단계가 끝날 때마다 한 줄로 보고합니다. 실패하면 오류 줄을 보여 주고 원인을 고친 뒤 다시 합니다.
- 만드는 것은 이 스킬 파일(`~/.claude/skills/jarvis-secretary/`), `~/jarvis`(프로그램), `~/jarvis-secretary`(비서 폴더)뿐입니다. 다른 폴더와 설정은 바꾸지 않습니다.

## 1. 이 스킬 설치

사용자가 이 파일을 주며 「이 스킬 설치해줘」라고 하면 먼저 이 절을 합니다.

1. `~/.claude/skills/jarvis-secretary/SKILL.md`가 이미 있으면 알려 주고, 덮어써도 되는지 물은 뒤 허락을 받으면 진행합니다.
2. 이 파일 전체를 요약하거나 고치지 말고 그대로 `~/.claude/skills/jarvis-secretary/SKILL.md`에 저장합니다.
3. 저장한 파일의 첫 줄이 `---`이고 `name: jarvis-secretary`가 있는지 확인합니다.
4. 이어서 2절부터 진행해도 되는지 묻습니다. 사용자가 「세팅까지 해줘」라고 했으면 묻지 않고 바로 진행합니다.

## 2. 준비 확인

1. 운영체제(윈도우 · 맥)를 확인합니다.
2. `git --version`과 `node -v`(20 이상)를 확인합니다. 없으면 무엇이 없는지 알려 주고, 사용자가 허락하면 설치합니다.
   - 윈도우: `winget install --id Git.Git -e` · `winget install --id OpenJS.NodeJS.LTS -e`
   - 맥: `xcode-select --install`(git), Node.js는 https://nodejs.org 의 LTS 설치 파일이나 `brew install node`
   - 설치한 뒤에는 새 터미널에서 다시 확인합니다.
3. 크롬이나 엣지가 있는지 확인합니다. 자비스 화면은 이 브라우저로 엽니다.
4. 터미널용 클로드 코드가 있는지 `claude --version`으로 확인합니다. 자비스의 두뇌는 터미널에서 로그인한 클로드 코드를 그대로 씁니다(원본 설명서: 「run `claude` once and complete login. The bridge reuses that login」). 없으면 공식 방법(`npm install -g @anthropic-ai/claude-code` 또는 https://docs.claude.com/en/docs/claude-code 의 설치 파일)으로 설치해도 되는지 묻고, 허락을 받으면 설치합니다. 설치한 뒤에는 사용자에게 터미널에서 `claude`를 한 번 실행해 로그인해 달라고 하고 기다립니다.
5. 사용자에게 한 번 알립니다: 클로드 유료 요금제가 필요하고, 자비스를 쓴 만큼 그 클로드 계정의 사용량이 들어갑니다.

## 3. 자비스 받기와 한국어 패치

1. `~/jarvis`가 이미 있으면 덮어쓰지 말고 어떻게 할지 묻습니다.
2. 원본을 받습니다.
   ```bash
   git clone https://github.com/adewaskar/jarvis.git ~/jarvis
   git -C ~/jarvis checkout 9ae5ec8
   ```
3. 한국어 패치를 받습니다. 아래 주소의 파일을 `~/jarvis/jarvis-ko.patch`로 내려받고, SHA-256이 같은지 확인합니다.
   - 주소: https://hub-hun.github.io/dplanner/skills/jarvis-secretary/jarvis-ko.patch
   - SHA-256: `14a5ad7c9fe5eb5737a76e6a667efbeb65fb24dfc01cb27c909e36e5c4791663`
   - 내려받지 못하거나 해시가 다르면, 노션 가이드에서 받은 `jarvis-ko.patch.txt`(다운로드 폴더)를 찾아 같은 해시인지 확인하고 씁니다.
4. 패치를 적용합니다.
   ```bash
   git -C ~/jarvis apply --check jarvis-ko.patch
   git -C ~/jarvis apply jarvis-ko.patch
   ```
5. `~/jarvis`에서 `npm install`, `npm run build`를 차례로 실행합니다. 빌드 끝에 `built in`이 보이면 성공입니다.
6. `~/jarvis`에서 `npm run setup`을 실행합니다. 원본이 준비물(Node.js · 클로드 코드 로그인 · 브라우저)을 쉬운 말로 점검해 줍니다. 빠진 것이 있으면 그 안내대로 채웁니다.

한국어 패치가 바꾸는 것: 한국어로 알아듣기, 「헤이 자비스」로 부르기, 한국어 여성 목소리, 해요체 말투와 호칭, 그리고 비서 폴더의 지도(CLAUDE.md)를 대화를 시작할 때마다 읽어 클로드에게 넘기기입니다.

## 4. 비서 폴더 만들기 (컨텍스트와 지도)

자비스는 `JARVIS_WORKSPACE` 폴더 안에서 일하고, 그 밖의 파일은 열지 않습니다. 이 폴더를 비서 전용 폴더로 만들고 맨 위에 지도 CLAUDE.md를 둡니다. 그러면 자비스가 「나는 누구고, 어떤 파일에 무엇이 있고, 어떤 규칙으로 일하는지」를 처음부터 알고 시작합니다.

1. 사용자에게 여섯 가지를 한 번에 묻습니다. 모르는 것은 비워 둬도 된다고 말합니다.
   1. 자비스가 부를 호칭(예: 팀장님)
   2. 회사와 팀
   3. 주로 하는 일
   4. 자주 연락하는 사람 · 거래처(이름과 관계만)
   5. 일정과 메일에 쓰는 도구(예: 구글 캘린더 · 지메일)
   6. 업무 도구 연결 방법(5절): A 크롬에 로그인된 계정 그대로 쓰기(터미널의 클로드 코드에서 `/chrome`으로 크롬 연결을 켤 수 있을 때) · B claude.ai 계정 커넥터(크롬 연결을 쓰지 않을 때). 고르기 어려워하면 A를 권합니다.
2. 호칭이 「팀장님」이 아니면 맞춥니다. 한국어 패치는 호칭을 「팀장님」으로 넣어 두었습니다. `~/jarvis/bridge/server.mjs`와 `~/jarvis/src/lib/fillers.ts`에 있는 「팀장님」을 모두 사용자가 고른 호칭으로 바꾸고, `~/jarvis`에서 `npm run build`를 다시 실행합니다.
3. 아래 구조로 `~/jarvis-secretary`를 만듭니다.
   ```text
   ~/jarvis-secretary/
   ├─ CLAUDE.md        지도: 폴더 안내와 비서 규칙 (자비스가 대화마다 읽음)
   ├─ profile.md       나: 호칭 · 회사 · 팀 · 하는 일
   ├─ work-rules.md    일하는 방식: 일정 · 메일 · 보고 규칙
   ├─ contacts.md      자주 연락하는 사람 · 거래처
   ├─ company.md       회사 · 제품 · 경쟁사 메모
   └─ notes/           「메모해 둬」라고 한 내용 (쓰기 모드에서 자비스가 씀)
   ```
4. `CLAUDE.md`는 아래 틀을 그대로 쓰고 〈 〉 칸만 답으로 채웁니다. 틀의 줄 앞 들여쓰기는 빼고 씁니다(첫 줄이 `# 비서 지도`). 답이 없는 칸은 「(비어 있음)」으로 둡니다.
   ```markdown
   # 비서 지도

   이 폴더는 〈호칭〉의 업무 비서 폴더예요. 대화를 시작할 때마다 이 지도를 읽고, 필요한 파일을 열어 일해요.

   ## 나
   - 호칭: 〈호칭〉 (대답할 때 이 호칭으로 불러요)
   - 회사 · 팀: 〈회사와 팀〉
   - 하는 일: 〈주로 하는 일〉

   ## 파일 안내
   | 파일 | 담은 것 | 열 때 |
   |---|---|---|
   | profile.md | 나에 대한 정보 | 내 업무에 맞춰 답하거나 나를 소개할 때 |
   | work-rules.md | 일정 · 메일 · 보고 규칙 | 일정을 넣거나 메일을 쓸 때 |
   | contacts.md | 자주 연락하는 사람 · 거래처 | 사람 이름이 나오거나 받는 사람을 정할 때 |
   | company.md | 회사 · 제품 · 경쟁사 메모 | 회사 · 업계 질문, 미팅 전 조사 |
   | notes/ | 「메모해 둬」라고 한 내용 | 지난 메모를 찾을 때 |

   ## 연결된 도구
   - 일정: 〈일정 도구〉
   - 메일: 〈메일 도구〉
   - 연결 방법: 〈크롬에 로그인된 계정 / claude.ai 계정 커넥터〉

   ## 일하는 규칙
   - 일정을 넣기 전에 날짜 · 시간 · 제목을 한 문장으로 말하고 넣어요.
   - 메일 보내기 · 일정 지우기 · 결제처럼 되돌리기 어려운 일은 하기 전에 한 문장으로 확인받아요.
   - 「메모해 둬」라고 하면 notes/ 아래 날짜 이름 파일(예: 2026-11-11.md)에 적어요.
   - 이 폴더 밖의 파일은 열지 않아요. 비밀번호 · 인증 코드는 어디에도 적지 않아요.
   ```
5. 나머지 파일은 아래처럼 만들고, `notes/`는 빈 폴더로 둡니다. 답이 없는 칸은 「(비어 있음)」으로 둡니다.
   - `profile.md`: `# 나` 아래에 호칭 · 회사와 팀 · 주로 하는 일
   - `work-rules.md`: `# 일하는 규칙` 아래에 CLAUDE.md의 「일하는 규칙」 네 줄, 그 아래 `## 더 정한 규칙`(사용자가 더 말한 규칙, 예: 회의는 30분 단위)
   - `contacts.md`: `# 사람 · 거래처` 아래에 `| 이름 | 관계 | 메모 |` 표
   - `company.md`: `# 회사 메모` 아래에 `## 회사` · `## 제품` · `## 경쟁사` 세 칸
6. 사용자에게 알립니다: 이 파일들은 언제든 직접 고쳐도 되고, 고친 내용은 다음 대화부터 반영됩니다.

## 5. 업무 도구 연결 (클로드가 화면을 열고 확인)

4절 6번에서 고른 방법으로 진행합니다.

### 방법 A: 크롬에 로그인된 구글 계정 그대로 쓰기 (권장)

자비스는 「Claude in Chrome」 확장을 통해 사용자의 크롬을 직접 조작합니다. 크롬에 이미 로그인된 구글 캘린더 · 지메일 · 드라이브를 그대로 쓰므로 구글 권한을 따로 주지 않아도 됩니다. 자비스는 클로드 코드가 크롬 확장과 연결할 때 만드는 통로(윈도우는 `\\.\pipe\claude-mcp-browser-bridge-<사용자 이름>`)를 같이 쓰기 때문에, 클로드 코드의 크롬 연결을 먼저 켜야 합니다.

1. 크롬에 Claude 확장(「Claude in Chrome」)이 설치되고 로그인돼 있는지 묻습니다. 없으면 크롬 웹 스토어에서 「Claude」를 검색해 설치하고, 확장 아이콘을 눌러 클로드 코드와 같은 클로드 계정으로 로그인하도록 안내합니다.
2. 사용자에게 터미널에서 `claude`를 실행하고 `/chrome`을 입력해 상태가 「Enabled」인지 보게 합니다. 꺼져 있으면 「Enabled by default」를 고르고, 처음 켰다면 크롬을 완전히 껐다가 다시 열게 합니다. 처음 켤 때 연결 설정 파일이 설치되고, 크롬은 시작할 때 그 파일을 읽기 때문입니다(클로드 코드 공식 문서). 사용자가 `/chrome`을 쓸 수 없다고 하면 3~4번은 건너뛰고 방법 B로 갑니다.
3. 크롬에서 https://calendar.google.com 과 https://mail.google.com 이 로그인된 계정으로 열리는지 확인합니다.
   - 이 클로드 코드가 크롬 도구를 쓸 수 있으면 직접 두 주소를 열어 로그인 상태만 확인합니다. 이 클로드 코드의 크롬 도구가 된다고 해서 자비스의 크롬 연결이 켜진 것은 아닙니다. 자비스 쪽 연결은 7절 실행 기록의 `browser control` 줄로 확인합니다.
   - 크롬 도구를 쓸 수 없으면 사용자에게 두 주소를 열어 보고 로그인돼 있는지 알려 달라고 합니다.
   - 어느 쪽이든 메일 내용 · 일정 내용은 읽거나 대화에 옮기지 않습니다.
4. 일정 넣기 · 메일 쓰기처럼 클릭과 입력이 필요한 일은 쓰기 모드에서만 됩니다. 6절에서 쓰기 모드를 켤지 묻습니다.
5. 터미널의 클로드 코드에서 크롬 연결을 켜지 않으면 자비스가 쓰는 크롬 통로가 생기지 않아서, 자비스의 크롬 조작이 켜지지 않습니다(클로드 데스크톱 앱의 크롬 연결만 있는 컴퓨터에서 확인). 이때는 방법 B로 바꿉니다.

### 방법 B: claude.ai 계정 커넥터 (크롬 연결을 쓰지 않을 때)

1. https://claude.ai/settings/connectors 를 열어 Google Calendar · Gmail · Google Drive의 「연결」을 누르도록 안내합니다. 구글 로그인과 권한 허용 버튼은 사용자가 누릅니다.
2. 6절 실행 파일에 `JARVIS_ACCOUNT_CONNECTORS=1`을 넣습니다. 원본 설명서 기준으로 커넥터는 대화의 두 번째 질문부터 들어오고, 일정 만들기 · 메일 보내기처럼 바꾸는 일은 쓰기 모드가 필요합니다.
3. 방법 A에서 B로 바꿨다면 `~/jarvis-secretary/CLAUDE.md`의 「연결 방법」 줄도 「claude.ai 계정 커넥터」로 고칩니다. 자비스가 대화마다 이 지도를 읽기 때문입니다.

## 6. 실행 파일 만들기

1. 쓰기 모드를 켤지 사용자에게 묻습니다. 한 번 이렇게 알립니다: 쓰기 모드(`--writes`)는 일정 넣기 · 메일 쓰기 같은 클릭과 입력을 켜고, 명령 실행 · 파일 쓰기도 함께 켭니다. 원본 설명서는 켜기 전에 `~/jarvis/bridge/policy.mjs`의 `decideTool`을 읽어 보라고 안내합니다. 읽기만 쓸 사람은 끕니다.
2. 실행 파일을 비서 폴더에 만듭니다. 방법 B가 아니면 커넥터 줄을 빼고, 쓰기 모드를 끈 사람은 `-- --writes`를 뺍니다.
   - 윈도우 `~/jarvis-secretary/start-jarvis.cmd` (두 번 누르면 실행)
     ```bat
     @echo off
     set JARVIS_WORKSPACE=%USERPROFILE%\jarvis-secretary
     set JARVIS_ACCOUNT_CONNECTORS=1
     cd /d %USERPROFILE%\jarvis
     npm start -- --writes
     ```
   - 맥 `~/jarvis-secretary/start-jarvis.command` (만든 뒤 `chmod +x`, 두 번 누르면 실행)
     ```bash
     #!/bin/bash
     export JARVIS_WORKSPACE="$HOME/jarvis-secretary"
     export JARVIS_ACCOUNT_CONNECTORS=1
     cd "$HOME/jarvis" && npm start -- --writes
     ```

## 7. 확인

1. 실행 파일을 돌리고, 터미널에 `[jarvis] context map` 줄이 비서 폴더의 CLAUDE.md 경로와 함께 찍히는지 봅니다. `context map none`이 나오면 `JARVIS_WORKSPACE` 경로를 다시 확인합니다.
2. 방법 A라면 `browser control ready` 줄이 찍히는지 봅니다. `browser control unavailable`이 나오면 5절 방법 A의 1~2번(확장 로그인, `/chrome` 연결, 크롬 다시 시작)을 다시 확인합니다. 그래도 같으면 방법 B로 바꿉니다(5절 B 3번까지). 방법 B라면 이 줄이 `unavailable`이어도 정상입니다. 자비스는 연결 방법과 상관없이 크롬 통로가 있는지만 찍기 때문입니다.
3. 터미널에 찍힌 주소(보통 http://localhost:5173)를 크롬이나 엣지의 일반 창으로 열고, INITIALISE를 누르고, 마이크를 허용하도록 안내합니다.
4. 「헤이 자비스, 오늘 일정 알려 줘」라고 말해 보도록 안내합니다.
5. 무엇을 만들고 무엇을 연결했는지 세 줄로 보고하고 끝냅니다.

## 막힐 때

- 목소리가 안 들리거나 못 알아들을 때: 자비스 화면에서 D를 누르면 진단 화면이 나옵니다. 크롬이나 엣지의 일반 창인지, 마이크를 허용했는지 봅니다.
- 포트가 이미 쓰이고 있다고 나올 때: 앞에 켠 자비스 창을 닫고 다시 실행합니다.
- 비서 폴더 내용을 바꾸고 싶을 때: 파일을 직접 고치거나 클로드 코드에 「비서 폴더 정리해줘」라고 부탁합니다. 이 스킬의 4절을 다시 진행합니다.

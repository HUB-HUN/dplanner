# FilmCraft × agent-desktop 조작 요령

FilmCraft 0.18.0 · agent-desktop 1.2.0 · 윈도우 10에서 2026-11-09에 직접 확인한 내용이다.
agent-desktop 스킬(`agent-desktop` 명령)이 먼저 설치돼 있어야 한다.

## 시작 전에

- FilmCraft 창은 최소화하지 않는다. 최소화한 창은 조작할 수 없다.
- 아래 「진짜 마우스」 단계가 들어가면, 시작하기 전에 사용자에게 「끝날 때까지 마우스와 키보드를 쓰지 말아 주세요」라고 말한다. 그 단계는 실제 마우스 포인터를 움직인다.
- 창을 정해진 자리와 크기에 두고 시작한다(예: `move-window --x=-7 --y 0`, `resize-window --width 1277 --height 1047`). 진짜 마우스 좌표는 그 상태에서 `screenshot`으로 확인해서 쓴다.
- FilmCraft를 처음 열 때 이전 세션을 복구할지 묻는 창이 뜰 수 있다. 지우지도 열지도 않는 「나중에」를 고른다.
- 진짜 마우스 동작 직전마다 사용자가 마우스 · 키보드를 쓰고 있지 않은지 확인하면 안전하다(윈도우: `GetLastInputInfo`로 마지막 입력 뒤 몇 초가 지났는지 본다).

## 진짜 마우스 없이 되는 것

FilmCraft 화면은 그림으로 그리지만, 메뉴 · 탭 · 이름 있는 칸은 접근성 트리에 나온다.

- 메뉴: 메뉴 막대의 단추(`파일` `편집` `클립` `시퀀스` `그래픽 및 제목` `창`)를 `click`하면 항목이 같은 창 트리에 나타난다. 항목 이름에는 단축키가 붙어 있다. 예: `가져오기… Ctrl+I`, `재생 헤드 위치에 자막 추가 Ctrl+Alt+C`.
- 작업 영역: `창` > `작업 영역` > `      편집 Alt+Shift+1`(이름 앞에 공백이 있다).
- 미디어 브라우저: 탭 `미디어 브라우저` → textfield `Path`에 폴더 경로를 `set-value` → `press return`. 윈도우 기본 「열기」 창 대신 이것을 쓴다.
- 앱이 맨 앞에 있으면 `press`로 단축키를 보낼 수 있다. 예: `home`(처음으로), `space`(재생 · 정지). 다만 2026-11-09 새 대화 시험에서는 헤드리스 `press end`로 재생 헤드가 옮겨지지 않았다. 재생 헤드는 눈금자를 진짜 마우스로 눌러 옮기는 편이 확실하다.

### 자막

1. 텍스트 패널을 연다(탭 `텍스트`).
2. 재생 헤드를 시퀀스 끝에 둔다(눈금자에서 시퀀스 끝 자리를 `--headed mouse-click`). 새 자막이 다른 자막과 겹치지 않게 하기 위해서다. 겹쳐 생겼으면 5번에서 시간을 고쳐 넣으면 된다.
3. `시퀀스` > `자막` > `재생 헤드 위치에 자막 추가 Ctrl+Alt+C`. 새 자막의 글은 `New caption`이다.
4. 자막이 두 줄 이상이면 줄마다 칸 이름이 같아서 `AMBIGUOUS_TARGET`으로 막힌다. 텍스트 패널의 textfield `검색`에 `New caption`을 넣어 새 줄 하나만 남긴다.
5. textfield `Caption in` → `Caption out` → `Caption text` 순서로 `set-value`한다. 시간은 타임코드(`00:00:01:04`)로 쓴다. 글을 바꾸면 그 줄이 검색에서 빠지므로 글을 마지막에 넣는다. 시작보다 끝을 먼저 넣으면 끝이 시작보다 앞서 거부될 수 있으니 순서를 지킨다.
6. 글을 넣은 뒤에는 `press return`을 쓰지 않는다. 글 칸에 줄바꿈이 들어가고 확정되지 않는다(2026-11-09 시험). 대신 `검색` 칸을 `clear`하면 초점이 옮겨지면서 글이 확정되고, 모든 줄이 다시 보인다. 줄마다 3~6번을 되풀이한다.
7. 자막 모양: incrementor `px`(글자 크기), switch `L` `C` `R`(정렬), `T` `M` `B`(위치), checkbox `상자`(배경 상자).

### 컷편집(빠른 컷 몽타주)

1. 파일을 타임라인 끝에 진짜 마우스로 끌어다 놓는다(아래 「진짜 마우스가 필요한 것」). 놓는 x 좌표 = 0초 자리 + 초당 픽셀 × 시작 시각.
2. 남길 길이의 끝 시각에 해당하는 타임라인 눈금자를 진짜 마우스로 눌러 재생 헤드를 옮긴다(`--headed mouse-click --xy`). 헤드리스 `press shift+right`는 Shift가 빠져 1프레임씩만 움직이니 쓰지 않는다.
3. `press w`(Ripple Trim Next Edit to Playhead)로 재생 헤드 뒤를 잘라 내고 뒤를 당긴다. 다음 파일은 재생 헤드 자리에 놓는다.
4. 다 놓으면 `시퀀스` > `빈 구간 제거`로 한두 프레임 벌어진 칸을 메꾼다.
5. 구간 하나만 들어낼 때는 `마커` > `시작 표시 I` · `끝 표시 O`로 범위를 잡고 `시퀀스` > `구간 삭제 (간격 닫기) '`를 누른다.

자막은 `px` 40 안팎에 `상자`를 켜면 작은 흰 글씨가 검정 반투명 상자에 담겨 깔끔하다(자막 트랙 전체에 걸린다). 100px 넘게 키우고 상자를 켜면 화면을 크게 가린다.

### 정갈한 편집(2026-11-09 시연에서 확인)

- 장면 전환: 먼저 `편집` > `모두 선택 해제 Ctrl+Shift+A`. 고른 클립이 있으면 `시퀀스` > `비디오 전환 적용 Ctrl+D`가 재생 헤드 자리가 아니라 그 클립 앞뒤에 걸린다. 반대로 이 성질을 쓰면 그래픽 클립 하나를 고른 채 Ctrl+D로 나타남 · 사라짐을 건다. 전환 길이는 `편집` > `설정` > `타임라인…`의 「비디오 전환 기본 길이」(이름 없는 숫자 칸, 진짜 마우스로 눌러 `ctrl+a` → 숫자 → `tab`).
- 오디오 게인: 클립을 진짜 마우스로 고르고 `클립` > `오디오 옵션` > `오디오 게인… G`. 창이 열리면 「게인 조정:」이 골라져 있다. 「게인 설정:」 radiobutton은 헤드리스 `click`이 시간 초과되고, 바로 아래 incrementor(이름 `dB`)는 같은 이름 칸이 넷이라 `set-value`가 거절된다. `snapshot --include-bounds`의 트리 순서로 라디오와 그다음 칸의 위치를 읽어 둘 다 진짜 마우스로 누른다. `press`에는 「-」 키 이름이 없으므로 `ctrl+a` → `0`을 넣고 `down`을 누른다(한 번에 0.1 dB, -16 dB면 160번) → `tab` → `확인`. 창을 다시 열면 「피크 진폭」이 그만큼 내려가 있어 적용을 확인할 수 있다. `shift+down` · `pagedown`으로는 크게 내려가지 않는다.
- 믹스 트랙 정규화: `시퀀스` > `믹스 트랙 정규화…` → 창 안의 dB 칸을 같은 방법으로 누르고 `0` → `down`(이 칸은 한 번에 1 dB) → `확인`. 「새로 생긴 칸」을 골라 값을 넣는 방식은 다른 패널의 검색 칸을 잡을 수 있으니 쓰지 않는다.
- 제목 그래픽: 재생 헤드를 둔 자리에 `기본 그래픽` 탭 > `찾아보기`의 템플릿을 진짜 마우스로 고르고 `적용`. 템플릿 속성의 textfield `Title` · `Subtitle`에 `set-value`(부제는 세로 영상에서 아주 작다). 길이는 그래픽 클립을 진짜 마우스로 고른 뒤 `클립` > `속도/지속 시간… Ctrl+R`의 textfield `길이:`(타임코드) → `확인`.
- 글꼴(자막 · 템플릿 속성): 이름 없는 콤보라 진짜 마우스로 연다. 목록 항목은 role `switch`이고 이름이 글꼴 이름이다. 헤드리스 `click`은 「ok」가 나와도 값이 그대로고, `select` · `get`은 같은 이름(또는 이름 없는) 콤보가 둘 이상이면 `AMBIGUOUS_TARGET`으로 거절된다. `snapshot --include-bounds`로 항목 위치를 읽고, 화면 밖이면 목록 위에서 `--headed mouse-wheel --dy -9`(한 칸에 40px쯤)를 굴려 보이게 한 뒤 진짜 마우스로 누른다. 고른 뒤 트리에서 콤보 값을 확인한다.
- 커서 여러 개: `session start --cursor --multi-agent`로 열고 동작마다 `--agent-id`를 바꾼다. 다른 커서로 패널 탭을 누를 때 「소스」 탭(소스 모니터)은 누르지 않는다. 소스 모니터가 앞에 오면 `시작 표시` · `끝 표시`가 그쪽에 걸려 `구간 삭제`가 엉뚱한 범위를 지운다.
- 동시에 여러 명령을 돌리면 agent-desktop이 오류 출력에 경고 줄을 쓸 때가 있다. JSON은 표준 출력만 읽는다(PowerShell 5.1은 JSON 읽기 실패에서 스크립트가 멈춘다).

### 내보내기

1. `파일` > `내보내기` > `미디어…`.
2. textfield `시퀀스 이름`(파일 이름)과 `폴더`(저장 위치)에 `set-value`. checkbox `Use the hardware encoder when available`, `가능하면 GPU에서 합성`은 이름으로 누를 수 있다.
3. 자막을 영상에 입히려면 아래 「진짜 마우스」의 목록 고르기가 필요하다. 내보내기 화면의 `자막` 섹션 머리도 트리에 없어서, 접혀 있으면 진짜 마우스로 눌러 펼친다.
4. 「내보내기」 단추도 트리에 없어서 진짜 마우스로 누른다.
5. 내보낸 뒤에는 꼭 확인한다: `filmcraft-cli --save-as check.fcproj import <영상>` → `filmcraft-cli --project check.fcproj --save exec file.newSequenceFromClip 'items=[1]'` → `filmcraft-cli --project check.fcproj render --seconds <초> --out frame.png`로 장면을 뽑아 자막이 들어갔는지 본다. 목록 고르기가 실패해도 내보내기는 성공으로 끝나기 때문이다.

## 진짜 마우스가 필요한 것(`--headed`)

- 미디어 브라우저 · 프로젝트 패널의 파일, 타임라인의 클립은 이름만 보이고(role `unknown`) 누르거나 끌 수 없다. 파일을 타임라인에 올릴 때는 `agent-desktop --headed drag --from-xy <파일 x,y> --to-xy <타임라인 x,y> --duration 650 --drop-delay 350`을 쓴다.
  - 빈 타임라인(「미디어를 여기에 놓아 시퀀스를 만드세요」)에 영상을 놓으면 그 영상의 크기 · 프레임에 맞는 시퀀스가 생긴다. 세로 영상이면 세로 시퀀스가 된다.
  - 오디오는 놓은 자리(커서의 x 좌표)에서 시작한다. 시간 눈금 두 개의 x 좌표로 1초당 픽셀을 재서 자리를 정한다.
- 펼친 목록의 항목: 헤드리스로 누르면 목록만 닫히고 값이 그대로다. 예: 내보내기 > `자막` > `내보내기 옵션` 목록은 진짜 마우스로 열고 `자막을 비디오에 번인`도 진짜 마우스로 고른다. 고른 뒤 트리에서 콤보 값이 바뀌었는지 확인한다.
- 이름 없는 칸과 콤보 상자(새 시퀀스의 가로 · 세로 칸, 찾기 창의 `Find What` 두 칸 등)는 쌍둥이라 거부된다. 다른 방법(빈 타임라인에 영상 놓기 등)을 찾는다.
- 맨 위 모드 탭(`가져오기` `편집` `내보내기`)도 트리에 없다. 내보내기 화면에서 편집 화면으로 돌아갈 때는 진짜 마우스로 `편집` 탭을 누른다.

## 하지 말 것

- 사용자가 마우스를 쓰는 중에는 `--headed` 동작을 하지 않는다.
- 화면을 녹화할 때 윈도우 기본 「열기」 창을 띄우지 않는다. 왼쪽 목록에 개인 폴더가 보인다.
- FilmCraft에는 자체 MCP 서버와 명령줄 도구가 있다. 사용자가 「화면 조작으로」라고 하면 그것으로 편집하지 말고 위 방법을 쓴다. 명령줄 도구는 결과 확인에만 쓴다.
